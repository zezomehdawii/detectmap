# Bundled MITRE ATT&CK reference catalog

The compressed STIX 2.1 bundles come from the [MITRE ATT&CK v20.1 release](https://github.com/mitre-attack/attack-stix-data/releases/tag/v20.1). New deployments use them to populate absent Enterprise, ICS, and Mobile reference catalogs. The product's ATT&CK refresh can update the catalog later.
